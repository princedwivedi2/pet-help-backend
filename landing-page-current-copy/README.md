# Current Respaw landing-page copy

This folder is a standalone HTML copy of the current Laravel landing page.
It was created before the Respaw purple/cream redesign so the existing page
can be reviewed and compared safely without changing the live Blade view.

## Open locally

Open `index.html` directly in a browser, or serve this folder with any static
HTTP server. The compiled landing-page CSS is stored in `assets/landing.css`.

The three existing page photographs still use the same Unsplash URLs as the
current Blade page. The audience switcher, scrolling effects, FAQ accordions,
waitlist confirmation, and back-to-top control remain included.

## Source snapshot

- Blade source: `resources/views/welcome.blade.php`
- Compiled CSS source: `public/css/landing.css`

The live source files were not changed while creating this copy.
